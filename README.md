# Top Restaurants de Montréal

Une application web élégante présentant une sélection des meilleurs restaurants de Montréal.

## Fonctionnalités

- Liste curatée des meilleurs restaurants
- Système de filtrage par type de cuisine
- Design responsive
- Notes et commentaires authentiques

## Structure du Projet

- `index.html` - Page principale
- `css/style.css` - Styles de l'application
- `js/main.js` - Logique de l'application
